본 앱은 PDF 파일에 텍스트 워터마크를 추가하는 문서 유틸리티입니다.

앱의 핵심 PDF 처리 기능은 기기 내부에서 수행되도록 설계되어 있습니다.

다만 광고 제공을 위해 사용하는 Unity Ads는 광고 식별자와 기기 정보 등 일부 기술적 정보를 별도로 처리할 수 있습니다.

1. 앱의 목적

본 앱은 사용자가 PDF 파일에 텍스트 워터마크를 추가하고 결과 문서를 저장할 수 있도록 도와주는 유틸리티 앱입니다.

개인, 업무 및 일반적인 문서 관리 목적으로 사용할 수 있습니다.

본 앱은 사용자가 직접 선택한 파일과 입력한 텍스트를 이용하여 워터마크를 생성합니다.

앱의 기본 기능을 사용하기 위해 회원가입이나 로그인은 필요하지 않습니다.

2. 수집 및 처리하는 정보

개발자는 앱의 핵심 기능을 위해 이용자의 이름, 이메일 주소, 전화번호, 주민등록번호 또는 결제정보 등을 별도로 입력하도록 요구하지 않습니다.

다만 앱 기능과 광고 서비스의 운영 과정에서 다음 정보가 처리될 수 있습니다.

2.1 사용자 파일 정보

  • 사용자가 직접 선택한 PDF 파일
  • 파일명, 파일 크기 및 파일 형식

  • 워터마크 작업을 위한 문서 페이지 정보
  • 사용자가 입력한 워터마크 텍스트
  • 워터마크가 적용된 결과 PDF 파일

2.2 앱 설정 정보

  • 앱 언어 설정
  • 워터마크 관련 사용자 설정
  • 앱 기능 사용을 위한 로컬 상태값
  • 광고 표시 빈도 관리를 위한 로컬 설정값

2.3 광고 관련 기술 정보

Unity Ads는 광고 제공과 성과 측정, 보안 및 부정행위 방지를 위해 다음과 같은 정보를 처리할 수 있습니다.

  • Android 광고 ID 및 기타 허용된 식별자

3. PDF 파일 및 로컬 처리

사용자가 선택한 PDF 파일은 워터마크 적용 작업을 수행하기 위해 기기 내부에서 처리되도록 설계되었습니다.

일반적인 워터마크 작업에서 문서 내용이나 사용자가 입력한 워터마크 텍스트를 개발자가 운영하는 서버로 전송하도록 설계하지 않았습니다.

3.1 파일 처리 과정

  • 사용자가 PDF 파일 선택
  • 선택한 PDF 파일 읽기
  • 워터마크 텍스트 입력
  • 선택한 문서에 워터마크 적용
  • 새로운 결과 PDF 파일 생성
  • 기기 저장소에 결과 저장

3.2 원본 파일

앱은 워터마크 작업을 위해 선택한 문서를 읽고 결과 파일을 생성합니다.

정상적인 작업 과정에서 원본 문서를 임의로 변경하거나 삭제하지 않는 것을 기본 원칙으로 합니다.

다만 실제 결과는 사용자가 선택한 저장 위치, 운영체제 및 파일 처리 방식에 따라 달라질 수 있습니다.

3.3 임시 데이터

워터마크 작업 중 임시 파일이나 캐시 데이터가 기기 내부에 생성될 수 있습니다.

해당 정보의 삭제 시점은 앱의 구현 방식과 운영체제의 저장소 관리 정책에 따라 달라질 수 있습니다.

4. 저작권 및 사용자 책임

본 앱은 사용자가 선택한 PDF 문서에 텍스트 워터마크를 추가하는 도구입니다.

개발자는 사용자가 선택하거나 생성한 PDF 문서, 텍스트, 이미지, 로고, 상표 또는 기타 콘텐츠에 관한 소유권을 주장하지 않습니다.

사용자는 문서를 수정하거나 워터마크를 적용할 수 있는 적법한 권한을 가지고 있어야 합니다.

사용자는 다음과 같은 행위를 해서는 안 됩니다.

  • 타인의 저작권을 침해하는 문서 수정
  • 상표권 또는 기타 지식재산권 침해
  • 타인의 개인정보를 부적절하게 공개
  • 계약상 권한을 위반하는 문서 사용
  • 문서의 출처 또는 소유권을 허위로 표시
  • 관련 법령을 위반하는 파일 배포

앱 자체의 독창적인 코드, 디자인 및 제작 콘텐츠에 관한 권리는 JCraft Studio 또는 정당한 권리자에게 있습니다.

5. 정부기관 또는 공식기관과의 관계

본 앱은 어떠한 정부기관, 공공기관, 문서 발급기관, 회사 또는 PDF 표준 관련 단체와도 공식적인 제휴 관계가 없습니다.

특정 기관이나 문서 형식이 언급되더라도 공식적인 승인, 후원 또는 인증을 의미하지 않습니다.

본 앱으로 생성한 워터마크는 문서의 진위, 소유권, 법적 효력 또는 공식 인증을 보장하지 않습니다.

일부 국가 또는 지역에서는 광고와 관련된 개인정보 처리에 사용자의 동의가 필요할 수 있습니다.

앱은 사용자가 요청하지 않은 무관한 파일에 의도적으로 접근하도록 설계되지 않았습니다.

이용자가 외부 클라우드 저장소에서 문서를 선택하거나 외부 앱으로 결과 파일을 공유하는 경우 해당 제공업체의 정책이 별도로 적용될 수 있습니다.

일반적인 워터마크 작업에서 문서 내용을 개발자 자체 서버에 업로드하지 않도록 설계되었습니다.

다만 Unity Ads 및 관련 광고 기술 협력사는 광고 제공, 성과 측정, 보안 및 부정행위 방지를 위해 광고 식별자, 기기 및 네트워크 정보 등을 처리하거나 공유할 수 있습니다.

사용자가 파일 공유 기능을 직접 실행하는 경우에는 선택한 외부 앱이나 서비스에 결과 파일이 전달될 수 있습니다.

관련 법령에 따른 적법한 요청이나 법적 의무가 있는 경우 정보가 필요한 범위에서 처리될 수 있습니다.

개발자는 앱의 안정적인 운영과 파일 처리 보안을 위해 합리적인 노력을 기울입니다.

PDF 문서 처리는 가능한 범위에서 사용자의 기기 내부에서 이루어지도록 설계되었습니다.

다만 모바일 기기, 저장소, 운영체제, 네트워크 및 외부 앱의 특성상 절대적인 보안을 보장할 수는 없습니다.

개인정보 또는 민감한 내용이 포함된 PDF 문서를 처리하는 경우 결과 파일의 저장 위치와 공유 대상을 신중하게 확인해야 합니다.

보호자는 아동이 파일이나 워터마크 문구에 불필요한 개인정보를 입력하거나 외부에 공유하지 않도록 안내할 수 있습니다.

아동 및 연령 제한 대상 이용자에게는 관련 법령, Google Play 정책 및 광고 서비스의 추가 보호 요건이 적용될 수 있습니다.

11. 책임 및 면책 안내

본 앱은 일반적인 PDF 문서 처리 유틸리티로 제공됩니다.

파일 손상, 암호화된 문서, 지원되지 않는 파일 구조, 저장공간 부족, 운영체제 제한 등으로 워터마크 작업이 실패할 수 있습니다.

이용자는 중요한 원본 문서를 작업 전에 별도로 백업하는 것이 좋습니다.

작업 완료 후에는 워터마크 적용 여부와 PDF 파일의 정상적인 열람 가능 여부를 직접 확인하는 것이 좋습니다.

사용자가 선택한 콘텐츠의 부적법한 이용, 무단 공유, 저작권 침해 및 관련 행위에 대한 책임은 관련 법령에 따라 판단됩니다.

개발자의 책임은 관련 법령에서 허용하는 범위 내에서 제한될 수 있습니다.

법령상 면제하거나 제한할 수 없는 책임은 해당 제한의 적용을 받지 않습니다.

앱 기능을 위해 생성된 임시 데이터나 일부 설정 정보는 기기 내부에 저장될 수 있습니다.

Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 일반적으로 앱 전용 저장소의 데이터가 삭제됩니다.

그러나 공유 저장소나 외부 저장소에 저장한 결과 PDF 파일은 앱 삭제 후에도 남아 있을 수 있습니다.

이러한 파일은 파일 관리자 등을 이용하여 별도로 삭제해야 할 수 있습니다.

운영체제의 백업 및 복원 기능에 따라 일부 데이터가 다시 복원될 수도 있습니다.

Unity Ads가 독립적으로 처리하는 정보의 보관 기간은 해당 서비스의 정책을 따릅니다.
