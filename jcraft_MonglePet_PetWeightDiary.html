2. Information stored through the App

The App allows you to enter and manage information relating to your pets. Depending on the features you use, this may include:

  • Pet names, species, breeds, sex, birth dates, or profile details
  • Pet profile images selected by the user
  • Weight records and target weight information
  • Food, treat, walking, playtime, and activity records
  • Body measurements and related notes
  • Reminder schedules and notification preferences
  • App settings and language preferences
  • Backup data created at the user’s request

This information is intended to describe pets and their daily records. Users should not enter unnecessary personal, confidential, medical, financial, or other sensitive information about themselves or other individuals.

3. Local data storage

Pet records and App settings are generally stored locally on the user’s device. The developer does not operate an account system or a dedicated server for receiving and centrally storing these pet records.

Information stored locally may remain on the device until it is deleted within the App, removed through the device settings, or deleted when the App is uninstalled. Device behavior may vary depending on the operating system, manufacturer, backup settings, or other device configuration.

Important: The App’s local storage design does not mean that no information is ever transmitted from the device. Third-party advertising services included in the App may process device, advertising, usage, and diagnostic information as described below.

4. JSON backup and restore

The App may allow users to export records as a JSON backup file and restore records from a selected backup file.

Backup creation is initiated by the user. The backup file is saved to a location selected or approved by the user through the device’s storage interface. The developer does not automatically receive the contents of the backup file.

Once a backup file has been exported, the user is responsible for:

  • Selecting an appropriate and secure storage location
  • Preventing unauthorized access to the backup file
  • Avoiding unintended sharing or uploading of the backup file
  • Deleting old or unnecessary backup files
  • Confirming that a selected restore file is valid and trusted

If a user independently uploads, sends, or synchronizes a backup file through a third-party storage or communication service, the processing of that file is governed by the selected third party’s privacy policy and terms.

2. 앱에서 저장되는 정보

앱은 사용자가 반려동물에 관한 정보를 직접 입력하고 관리할 수 있도록 지원합니다. 사용하는 기능에 따라 다음 정보가 포함될 수 있습니다.

  • 반려동물 이름, 종류, 품종, 성별, 생일 및 프로필 정보
  • 사용자가 선택한 반려동물 프로필 이미지
  • 체중 기록 및 목표 체중 정보
  • 사료, 간식, 산책, 놀이 및 활동 기록
  • 신체 치수와 관련 메모
  • 알림 일정과 알림 설정
  • 앱 설정 및 언어 설정
  • 사용자의 요청에 따라 생성한 백업 데이터

위 정보는 반려동물과 반려동물의 생활 기록을 관리하기 위한 것입니다. 사용자는 본인 또는 다른 사람에 관한 불필요한 개인정보, 기밀정보, 의료정보, 금융정보 또는 기타 민감정보를 입력하지 않아야 합니다.

3. 기기 내부 저장

반려동물 기록과 앱 설정은 일반적으로 사용자의 기기 내부에 저장됩니다. 개발자는 해당 반려동물 기록을 전송받아 중앙에서 보관하기 위한 자체 회원계정 시스템이나 전용 서버를 운영하지 않습니다.

기기에 저장된 정보는 사용자가 앱에서 삭제하거나, 기기 설정에서 앱 데이터를 삭제하거나, 앱을 제거할 때까지 기기에 남아 있을 수 있습니다. 실제 삭제 방식은 운영체제, 기기 제조사, 백업 설정 및 기타 기기 환경에 따라 달라질 수 있습니다.

중요: 앱 기록을 기기에 저장한다는 것이 기기에서 어떠한 정보도 전송되지 않는다는 뜻은 아닙니다. 앱에 포함된 제3자 광고 서비스는 아래 내용에 따라 기기, 광고, 앱 이용 및 진단 정보를 처리할 수 있습니다.

4. JSON 백업 및 복원

앱은 사용자가 기록을 JSON 백업 파일로 내보내거나, 사용자가 선택한 백업 파일에서 기록을 복원할 수 있도록 지원할 수 있습니다.

백업 생성은 사용자의 명시적인 동작에 따라 실행됩니다. 백업 파일은 기기의 파일 선택 화면을 통해 사용자가 선택하거나 승인한 위치에 저장됩니다. 개발자는 백업 파일의 내용을 자동으로 전송받지 않습니다.

백업 파일을 내보낸 이후에는 사용자가 다음 사항을 관리할 책임이 있습니다.

  • 안전하고 적절한 백업 저장 위치 선택
  • 백업 파일에 대한 무단 접근 방지
  • 백업 파일의 의도하지 않은 공유 또는 업로드 방지
  • 오래되거나 불필요한 백업 파일의 삭제
  • 복원에 사용하는 파일의 유효성과 신뢰성 확인

사용자가 백업 파일을 제3자 클라우드, 파일 저장소, 이메일, 메신저 또는 기타 서비스를 통해 직접 전송하거나 동기화하는 경우, 해당 파일의 처리는 사용자가 선택한 제3자 서비스의 개인정보처리방침과 이용약관에 따릅니다.
