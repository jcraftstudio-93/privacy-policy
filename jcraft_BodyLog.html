1. 개인정보처리방침 개요

JCraft Studio(이하 "개발자")는 BodyLog - Weight & BMI Tracker (이하 "앱") 사용자의 개인정보와 데이터를 중요하게 생각합니다.

본 개인정보처리방침은 앱이 어떤 데이터를 처리하는지, 데이터가 어떤 목적으로 사용되는지, 데이터가 어디에 저장되는지, 그리고 제3자 서비스가 어떤 방식으로 데이터를 처리할 수 있는지를 설명합니다.

앱을 설치하거나 이용하는 경우 본 개인정보처리방침의 내용을 확인한 것으로 간주됩니다. 다만 관련 법령에 따라 별도의 동의가 요구되는 데이터 처리에 대해서는 필요한 경우 별도의 동의 절차가 적용될 수 있습니다.

3. 앱에서 사용자가 입력하는 데이터

BodyLog는 앱의 핵심 기능을 제공하기 위해 사용자가 직접 입력한 다음과 같은 정보를 처리할 수 있습니다.

  • 체중
  • 신장(키)
  • 목표 체중
  • 체중 측정 날짜 및 시간
  • 체중 기록에 사용자가 작성한 메모
  • BMI 계산을 위해 필요한 정보
  • 체중 측정 알림 설정
  • 앱 언어, 다크 모드 등 앱 환경설정
이러한 체중 기록 및 관련 정보는 원칙적으로 사용자의 기기 내부에 저장되며, JCraft Studio가 운영하는 별도의 서버로 전송하여 저장하도록 설계되어 있지 않습니다.

4. 건강 관련 정보

체중, 신장 및 BMI와 같은 정보는 사용자의 건강 상태와 관련될 수 있는 정보입니다.

BodyLog는 이러한 정보를 체중 기록, BMI 계산, 체중 변화 확인 및 목표 체중 관리 등 사용자가 요청한 앱 기능을 제공하기 위해 사용합니다.

개발자는 앱에 입력된 체중 및 BMI 기록을 광고 목적으로 직접 판매하거나, 개발자가 운영하는 서버에 업로드하여 사용자 프로필을 구축하는 용도로 사용하지 않습니다.

5. 데이터 저장 방식

사용자가 BodyLog에 입력한 주요 앱 데이터는 사용자의 기기 내부 저장공간에 저장됩니다.

앱을 삭제하거나 앱 데이터를 삭제할 경우 기기에 저장된 데이터가 삭제될 수 있습니다.

기기 분실, 앱 삭제, 운영체제 오류, 저장소 손상, 사용자 조작 등으로 인한 데이터 손실을 방지하기 위해 중요한 기록은 사용자가 직접 백업할 것을 권장합니다.

6. JSON 백업 및 복원

BodyLog는 사용자가 자신의 데이터를 직접 보관할 수 있도록 JSON 형식의 백업 및 복원 기능을 제공할 수 있습니다.

백업 기능을 사용하는 경우 사용자가 선택한 위치에 BodyLog 데이터가 포함된 파일이 생성될 수 있습니다.

생성된 백업 파일의 보관, 복사, 전송, 공유 및 삭제에 대한 관리는 사용자에게 있습니다.

사용자가 백업 파일을 클라우드 저장소, 이메일, 메신저 또는 기타 제3자 서비스에 직접 업로드하거나 공유하는 경우, 해당 서비스의 개인정보처리방침과 보안 정책이 적용됩니다.

7. 알림 기능

BodyLog는 사용자가 설정한 체중 측정 일정을 알려주기 위해 기기의 로컬 알림 기능을 사용할 수 있습니다.

알림 기능을 사용하기 위해 운영체제의 알림 권한이 요청될 수 있으며, 사용자는 기기 설정에서 언제든지 알림 권한을 변경하거나 알림을 비활성화할 수 있습니다.

알림 일정은 체중 측정 알림을 제공하기 위한 목적으로 사용됩니다.

15. 의료 및 건강 관련 고지

BodyLog는 의료기기, 의료서비스 또는 의료진을 대체하는 서비스가 아닙니다.

앱이 제공하는 BMI, 체중 변화, 적정 체중 범위 및 기타 계산 결과는 일반적인 정보와 개인 기록 관리를 위한 참고 자료입니다.

BMI는 개인의 건강 상태, 체지방률, 근육량, 질병 여부, 임신 여부, 연령 및 기타 의학적 요소를 완전히 반영하지 못할 수 있습니다.

앱의 정보를 질병의 진단, 치료, 예방, 투약 결정 또는 긴급한 의료 판단에 사용해서는 안 됩니다.

건강 또는 체중과 관련하여 우려되는 증상이 있거나 의료적 판단이 필요한 경우 의사 또는 자격을 갖춘 의료 전문가와 상담해야 합니다.
