개인정보처리방침

본 개인정보처리방침은 JCraft Studio가 제공하는 Simple Zip Maker (이하 "앱")에 적용됩니다.

본 앱은 사용자가 선택한 파일을 ZIP 압축 파일로 생성하기 위한 유틸리티 애플리케이션입니다.

앱은 사용자의 기기 내부에서 파일을 처리하고 ZIP 파일을 생성하도록 설계되었습니다.

중요 안내

사용자가 선택한 파일과 ZIP 생성 결과는 앱의 핵심 기능을 위해 기기 내부에서 처리됩니다.

광고 제공에 사용되는 Unity LevelPlay와 Unity Ads는 파일 내용과 별도로 일부 기기 및 광고 관련 기술 정보를 처리할 수 있습니다.

최종 수정일: 2026년 11월 4일

1. 수집 및 처리하는 정보

본 앱은 회원가입이나 별도의 사용자 계정을 요구하지 않습니다.

개발자는 ZIP 파일 생성 기능을 제공하기 위해 사용자의 이름, 이메일 주소, 전화번호, 주민등록번호, 결제정보 등 직접 식별 가능한 개인정보를 별도로 요구하지 않습니다.

다만 앱 기능과 광고 제공 과정에서 다음과 같은 정보가 처리될 수 있습니다.

1.1 파일 관련 정보

  • 사용자가 선택한 파일
  • 파일명 및 파일 형식
  • 파일 크기와 접근에 필요한 정보
  • 사용자가 지정한 ZIP 생성 설정
  • 생성된 ZIP 파일 정보
  • ZIP 생성 기록 및 관련 로컬 데이터

1.2 앱 설정 정보

  • 앱의 언어 설정
  • 사용자가 저장한 앱 설정
  • ZIP 생성 기능 관련 로컬 상태값
  • 광고 표시 주기 관련 로컬 설정값

1.3 광고 관련 정보

광고 SDK는 광고 제공, 광고 성과 측정, 서비스 보안 및 부정행위 방지를 위해 일부 정보를 처리할 수 있습니다.

  • Android 광고 ID 등 광고 식별자
  • 기기 모델 및 운영체제 정보
  • IP 주소 및 대략적인 위치 정보
  • 광고 노출·클릭·시청 정보
  • SDK 오류 및 진단 정보
  • 광고 부정행위 탐지 관련 정보

실제 처리되는 항목은 SDK 버전, 연결된 광고 네트워크, 기기 설정, 지역 및 관련 법령에 따라 달라질 수 있습니다.

2. 정보 이용 목적

  • 사용자가 선택한 파일의 ZIP 압축
  • ZIP 파일 생성 및 저장
  • ZIP 생성 기록 관리
  • 앱 설정 및 언어 설정 유지
  • 파일 처리 오류 확인
  • 앱 안정성 및 성능 개선
  • 광고 제공 및 성과 측정
  • 광고 표시 빈도 관리
  • 서비스 보안 및 부정행위 방지
  • 관련 법적 의무 준수

3. 파일 처리 방식

본 앱은 사용자가 선택한 파일을 ZIP 형식으로 압축하기 위해 해당 파일에 접근합니다.

사용자가 선택한 파일의 내용은 ZIP 생성 기능을 수행하기 위한 범위에서 기기 내부에서 처리됩니다.

개발자는 정상적인 ZIP 생성 과정에서 사용자 파일의 내용을 별도의 개발자 운영 서버에 업로드하지 않습니다.

3.1 ZIP 생성 과정

  • 사용자가 압축할 파일 선택
  • 선택한 파일의 접근 및 읽기
  • 파일 데이터의 ZIP 압축 처리
  • 압축 결과 ZIP 파일 생성
  • 기기 저장소에 결과 파일 저장
  • 지원되는 경우 최근 작업 기록 저장

3.2 원본 파일

앱은 원본 파일의 내용을 읽어 ZIP 파일을 생성하도록 설계되었으며, 정상적인 ZIP 생성 과정에서 원본 파일을 임의로 삭제하거나 변경하지 않는 것을 기본으로 합니다.

다만 기기 상태, 파일 접근 권한 또는 저장소 오류 등에 따라 파일 처리에 문제가 발생할 수 있습니다.

3.3 임시 데이터

ZIP 생성 과정에서 작업용 임시 파일이나 캐시 데이터가 기기 내부에 생성될 수 있습니다.

해당 데이터의 보관 및 삭제 시점은 앱의 실제 구현과 운영체제의 저장소 관리 방식에 따라 달라질 수 있습니다.

4. 파일 접근 권한

파일 접근 권한은 사용자가 직접 요청한 파일 선택 및 ZIP 생성 기능을 제공하기 위한 목적으로 사용됩니다.

앱은 사용자의 동작과 관련 없는 파일에 의도적으로 접근하거나 불필요한 파일 내용을 수집하도록 설계되지 않았습니다.

Android의 파일 선택기, 저장소 접근 기능 또는 관련 권한은 운영체제 버전과 앱 구현에 따라 다르게 적용될 수 있습니다.

사용자가 외부 저장소나 클라우드 파일 제공업체에서 파일을 선택하는 경우 해당 제공업체의 개인정보처리방침이 별도로 적용될 수 있습니다.

5. 데이터 저장 및 삭제

5.1 로컬 저장

앱은 ZIP 생성 기록, 파일 관련 정보, 앱 설정 등을 사용자 편의를 위해 기기 내부에 저장할 수 있습니다.

이러한 데이터는 앱 기능을 제공하고 사용자의 설정을 유지하기 위해 사용됩니다.

5.2 생성된 ZIP 파일

생성된 ZIP 파일은 앱 내부 저장소 또는 사용자가 선택한 기기 저장 위치에 저장될 수 있습니다.

ZIP 파일의 실제 저장 위치에 따라 앱을 삭제하더라도 결과 파일이 계속 남아 있을 수 있습니다.

5.3 데이터 삭제

앱에서 ZIP 생성 기록 삭제 기능을 제공하는 경우, 해당 기능으로 일부 기록을 삭제할 수 있습니다.

Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 일반적으로 앱 내부에 저장된 로컬 데이터가 삭제됩니다.

다만 외부 저장소에 저장한 ZIP 파일이나 다른 앱으로 복사·공유한 파일은 사용자가 별도로 삭제해야 할 수 있습니다.

기기의 백업 및 복원 기능에 따라 일부 로컬 데이터가 복원될 수도 있습니다.

6. 광고 및 제3자 서비스

본 앱은 광고 미디에이션을 위해 Unity LevelPlay를 사용하며, 광고 제공을 위해 Unity Ads를 사용합니다.

6.1 Unity LevelPlay

Unity LevelPlay는 광고 요청, 광고 형식, 연결된 광고 네트워크, 광고 성과 및 수익화 운영을 관리하는 미디에이션 플랫폼입니다.

6.2 Unity Ads

Unity Ads는 앱 내부에 광고를 표시하는 광고 서비스입니다.

Unity Ads 및 관련 광고 기술 협력사는 광고 제공, 성과 측정, 서비스 보안, 부정행위 방지를 위해 기술적 정보를 처리할 수 있습니다.

6.3 광고 데이터 유형

6.4 광고 개인화

이용자의 지역, 기기 설정, 개인정보 보호 선택 및 관련 법령에 따라 개인화 또는 비개인화 광고가 제공될 수 있습니다.

일부 국가 또는 지역에서는 광고 관련 개인정보 처리에 이용자의 동의가 필요할 수 있습니다.

법령상 필요한 경우 적절한 동의 절차 및 개인정보 보호 선택 기능을 적용해야 합니다.

개인화 광고를 제한하더라도 모든 광고 표시가 중단되는 것은 아닙니다.

6.5 Unity 공식 개인정보처리방침

  • Unity Privacy Policy
  • Unity Game Player and App User Privacy FAQ

광고 서비스의 데이터 처리 범위는 실제 SDK 구성과 연결된 광고 네트워크에 따라 달라질 수 있습니다.

7. 개인정보의 제3자 처리 및 공유

개발자는 사용자가 선택한 파일 내용이나 생성된 ZIP 파일을 판매하지 않습니다.

앱의 일반적인 ZIP 생성 과정에서 파일 내용을 개발자의 자체 서버에 업로드하여 임의로 제3자에게 제공하지 않습니다.

다만 Unity LevelPlay, Unity Ads 및 관련 광고 기술 협력사는 광고 제공, 성과 측정, 보안 및 부정행위 방지를 위해 관련 정보를 처리하거나 공유할 수 있습니다.

이용자가 ZIP 파일을 외부 앱이나 클라우드 저장소에 직접 공유하는 경우 해당 서비스가 파일을 처리할 수 있습니다.

관련 법령에 따른 적법한 요청이나 법적 의무가 있는 경우 필요한 범위에서 정보가 처리될 수 있습니다.

8. 아동의 개인정보

본 앱은 일반적인 ZIP 파일 생성 도구로, 아동을 주요 대상으로 설계한 서비스가 아닙니다.

앱의 기본 기능을 제공하기 위해 아동의 이름, 연락처, 기타 직접 식별 가능한 개인정보를 요구하지 않습니다.

보호자는 아동이 파일 선택이나 공유 기능을 사용할 때 개인정보가 포함된 파일을 부적절하게 공유하지 않도록 주의할 수 있습니다.

아동 및 연령 제한 대상 이용자에게는 관련 법령과 Google Play 정책, 광고 네트워크의 추가 보호 요건이 적용될 수 있습니다.

9. 정보 보안

개발자는 파일 처리와 앱 운영의 안정성을 위해 합리적인 보안 조치를 고려합니다.

다만 기기의 보안 상태, 운영체제 제한, 저장소 오류, 악성코드, 외부 앱의 동작 등 모든 환경에서 완전한 보안을 보장할 수는 없습니다.

ZIP 파일은 압축 형식이며, 압축 자체가 파일 내용을 암호화하거나 기밀성을 보장하는 것은 아닙니다.

비밀번호 보호나 암호화가 별도로 적용되지 않은 ZIP 파일은 다른 사람이 접근할 경우 내부 내용을 확인할 수 있습니다.

민감한 파일을 저장하거나 공유하는 경우에는 접근 권한과 공유 대상을 주의해서 확인해야 합니다.

10. 저작권 및 파일 이용 권한

본 앱은 사용자가 선택한 파일을 ZIP으로 압축하는 유틸리티 도구입니다.

압축 대상 파일의 저작권과 기타 권리는 해당 파일의 정당한 권리자에게 귀속됩니다.

사용자는 적법한 접근 및 이용 권한을 가진 파일만 압축해야 합니다.

타인의 저작권, 개인정보, 영업비밀 및 기타 권리를 침해할 목적으로 앱을 이용해서는 안 됩니다.

앱 자체의 독창적인 소프트웨어 코드, 디자인 및 제작 콘텐츠는 JCraft Studio 또는 정당한 권리자의 권리에 속합니다.

Unity, Unity LevelPlay, Unity Ads, Google Play 등 제3자의 상표는 각 권리자에게 귀속됩니다.

11. 책임 및 면책 안내

본 앱은 일반적인 ZIP 파일 생성용 유틸리티로 제공됩니다.

파일 형식, 파일 손상, 접근 권한, 저장공간 부족, 운영체제의 제한 등에 따라 ZIP 생성이 실패할 수 있습니다.

중요한 파일은 ZIP 생성 전에 원본을 별도로 백업하는 것이 좋습니다.

ZIP 생성 완료 후에는 결과 파일이 정상적으로 열리고 필요한 파일이 모두 포함되었는지 직접 확인하는 것이 좋습니다.

관련 법령에서 허용하는 범위 내에서 개발자의 책임은 제한될 수 있습니다.

다만 법령상 면제하거나 제한할 수 없는 책임은 해당 제한의 적용을 받지 않습니다.

12. 이용자의 개인정보 보호 권리

이용자는 관련 법령에 따라 개인정보의 열람, 정정, 삭제, 처리 제한 및 기타 개인정보 보호 권리를 행사할 수 있습니다.

  • 앱에서 제공하는 ZIP 기록 삭제 기능 이용
  • Android 설정에서 앱 데이터 삭제
  • 앱 제거를 통한 로컬 데이터 삭제
  • 생성된 ZIP 파일 직접 삭제
  • Android 광고 ID 관리 또는 삭제
  • Unity 개인정보 보호 요청 절차 확인
  • Google Play 개발자 연락처를 통한 문의

제3자 광고 서비스가 독립적으로 처리하는 정보는 해당 제공업체의 개인정보 보호 절차에 따라 요청해야 할 수 있습니다.

13. 개인정보처리방침 변경

본 개인정보처리방침은 앱 기능, 광고 SDK, 데이터 처리 방식, 관련 법령 또는 플랫폼 정책 변경에 따라 수정될 수 있습니다.

수정된 내용은 본 페이지에 게시되며 최종 수정일을 갱신합니다.

관련 법령상 필요한 경우 중요한 변경 사항에 대해 추가 안내 또는 동의 절차가 적용될 수 있습니다.

앱 기능, 파일 처리, 개인정보 및 데이터 삭제 관련 문의는 Google Play 스토어에 게시된 개발자 연락처를 참고하시기 바랍니다.

Unity 광고 관련 개인정보 문의는 Unity 공식 개인정보 보호 자료를 참고할 수 있습니다.

3. File Processing

The App accesses files selected by users in order to create ZIP archives.

File contents are processed on the user's device as needed for ZIP creation.

The Developer does not upload file contents to a separate developer-operated server during normal ZIP creation.

3.1 ZIP Creation Process

  • Selecting files for compression.
  • Reading selected file data.
  • Compressing file data into ZIP format.
  • Generating a ZIP archive.
  • Saving the ZIP archive on the device.
  • Saving recent history, where supported.

3.2 Original Files

The App is designed to read selected original files to create ZIP archives, without intentionally modifying or deleting those originals during normal operation.

File processing errors may still occur due to device conditions, permissions, or storage issues.

3.3 Temporary Data

Temporary files or cache data may be generated locally during ZIP creation.

Handling and deletion of temporary data depend on App implementation and operating system storage management.

4. File Access Permissions

File access permissions are used to select and read files requested by users for ZIP creation.

The App is not designed to intentionally access unrelated files or collect unnecessary file contents.

5. Data Storage and Deletion

5.1 Local Storage

The App may store ZIP creation history, file information, and application settings locally on the device.

Such data is used to provide App features and preserve preferences.

5.2 Generated ZIP Archives

Generated ZIP files may be stored in private App storage or a device location selected by the user.

ZIP files saved outside the App's private storage may remain available after the App is uninstalled.

5.3 Data Deletion

Where an in-App history deletion feature is available, users may remove certain saved records.
